# Feature coverage

Generated by `apple/scripts/feature-coverage.sh` (do not edit). How the iOS app reaches each engine command that has
a place in the desktop menus: `swift+menu` / `swift` = referenced by the Swift sources, `menu` = the generated menus
and command palette (which cover every engine catalog command), `excluded` = cannot work on iOS
(`bridge/ios-excluded-commands.txt`). Desktop tools and panels are mapped in `docs/tool-map.toml`.
